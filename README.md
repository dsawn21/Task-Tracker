# Список дел в терминале

https://roadmap.sh/projects/task-tracker

Это маленькая программа на Python: записываешь дела в командной строке, а они сохраняются в файл. Ничего ставить не нужно — достаточно Python 3.8 или новее.

Файл программы: `task_cli.py`.  
Файл с делами: `tasks.json` — лежит **рядом со скриптом**, а не в той папке, откуда ты его запустил. Список один и тот же, откуда бы ни вызывал программу.

## Как запустить

В проводнике зайди в папку `d:\питон\sad` (или открой её в терминале) и напиши:

```bash
python task_cli.py
```

Появится список незакрытых дел. Дальше можно сразу писать команды после `>`. Выход — `q` или пустая строка.

Справка:

```bash
python task_cli.py help
```

## Что такое номер задачи

У каждого дела есть номер: `#1`, `#2`, `#3`…  
Его выдаёт программа при добавлении. Этот номер нужен, чтобы закрыть, переименовать или удалить конкретное дело.

Важно: цифры **1–7 в начале строки — это команды** (см. таблицу ниже). Номер задачи пишется **вторым**.

Пример: закрыть дело №4 → `3 4` или `done 4`.

## Команды

Можно писать словом или цифрой — одно и то же.

| Цифра | Слово | Что делает | Пример |
|------:|-------|------------|--------|
| 1 | `add` | Добавить дело | `1 купить хлеб` |
| 2 | `start` | Взять в работу | `2 4` |
| 3 | `done` | Отметить готовым | `3 4` |
| 4 | `todo` | Вернуть в «ждёт» | `4 4` |
| 5 | `upd` | Поменять текст | `5 4 купить хлеб и молоко` |
| 6 | `rm` | Удалить | `6 4` |
| 7 | `ls` | Показать список | `7` или `7 все` |

Кавычки вокруг текста **не нужны**.

Ещё проще: если написать просто фразу без команды, программа сама добавит дело:

```bash
python task_cli.py купить хлеб
```

Если текст **сам начинается с цифры 1–7**, команду `add` лучше указать явно:

```bash
python task_cli.py add 3 литра молока
```

## Как выглядит список

```text
#1   в работе  купить хлеб
#2   ждёт      позвонить маме
```

Три состояния:

- **ждёт** — ещё не начал;
- **в работе** — занимаешься этим;
- **готово** — сделано.

По умолчанию `ls` (и запуск без команды) показывает только незакрытые. Все дела сразу:

```bash
python task_cli.py ls все
```

Только готовые: `ls готово`. Только «ждёт»: `ls todo`. Только «в работе»: `ls работа`.

## Примеры Дел

```bash
python task_cli.py add купить хлеб
python task_cli.py add позвонить маме
python task_cli.py start 1
python task_cli.py done 1
python task_cli.py ls все
python task_cli.py rm 2
```

Или в интерактивном режиме:

```text
python task_cli.py
> 1 купить хлеб
> 2 1
> 3 1
> q
```

## Как хранятся данные

В `tasks.json` каждая запись выглядит примерно так:

```json
{
  "id": 1,
  "description": "купить хлеб",
  "status": "in-progress",
  "createdAt": "2026-10-06 00:08",
  "updatedAt": "2026-10-06 00:12"
}
```

`status` внутри файла английский (`todo` / `in-progress` / `done`), на экране — по-русски. Новый номер = самый большой существующий + 1. Удалённые номера заново не выдаются.

Файл создаётся сам при первом добавлении дела. Если JSON сломается, программа скажет об этом — тогда почини файл или удали его (список обнулится).

## Если что-то пошло не так

Частые причины:

- забыл номер задачи у `start` / `done` / `rm`;
- такого номера нет;
- пустой текст у `add`;
- после `ls` написал неизвестный фильтр.

Ошибка печатается в консоль, программа не падает «страшной простынёй». Старые длинные имена (`update`, `delete`, `mark-done`, `mark-in-progress`) тоже ещё работают.
